## 1. 盤點：現有的實作

### 1.1 八種天氣能重用的姿勢與環境

| 天氣 | 日常姿勢（`Poses`） | 週期 | 表情／一筆 | 環境（`Mowan.render`） | 彩蛋能借的 |
|---|---|---|---|---|---|
| 晴 SUNNY | `sunny`：雙手往斜上方慢慢伸懶腰 | 5.5 s | 閉眼笑、一筆翹起 | 太陽 | 伸懶腰的手臂（5 點）、閉眼笑 |
| 雨 RAINY | `rainy`：右手撐傘、傘輕輕晃 | 4.2 s | 皺眉、一筆垂下 | 雨絲（8fps 換步）、地上淡淡的水影 | 傘的握點與角度 `umbrellaAngle`、STARTLE 表情 |
| 雪 SNOW | `snow`：抬頭看雪、手收在兩側，每 4 s 縮一下 | — | 一般 | 雪花、雪堆 | 手收起的 5 點手臂、圍巾拉高、COLD 表情 |
| 熱 HOT | `hot`：右手沿臉頰擦汗 | — | 瞇眼平嘴 | 汗滴 | 擦汗的抬手／放手中間姿勢 |
| 陰 CLOUDY | `cloudy`：抬頭、視線跟著雲 | — | 一般 | 雲 | 視線跟隨 |
| 霧 FOG | `fog`：探頭、左手往前試探 | — | 瞇眼 | 霧帶 | 往前伸的左手 |
| 雷雨 THUNDER | `thunder`：雙手握傘柄，打雷時嚇一跳 | 同雨 | STARTLE | 雨＋閃電 `bolt` | 閃電觸發的驚嚇（`sinceStrikeMs`） |
| 冷 COLD | `cold`：抱自己、縮脖子、一陣陣發抖 | — | 閉眼細眉、波浪嘴 | 白氣 `breath` | 發抖 `jittered`、白氣 |

所有天氣的手臂都是 5 個控制點（雨天日常的手是 4 點），所以關鍵影格能互相內插。彩蛋**只用這些既有的姿勢欄位**（`armL/armR/headAngle/gaze/face/flick/umbrellaAngle/effects`），沒有新增任何部件或美術。

### 1.2 小墨丸與大墨丸的繪製

| | 日曆小墨丸 | 故事卡大墨丸 |
|---|---|---|
| 元件 | 日曆頁 RemoteViews 版面裡的 `ImageView`（`mowan_still`），內容是 `MowanBitmap.still` 畫好的**一張靜態圖** | `MowanView`，自己畫 |
| 大小 | 約 60dp，簡化細節（`Detail.of`） | 96×128dp，`Detail.FULL` |
| 動畫 | 沒有（D-48：日曆墨丸靜止，不能點） | 線條抖動 6fps（`BOIL_MS`）、雨 8fps、天氣日常循環（`MowanTimeline`） |
| 桌面小工具 | 同一個 RemoteViews 版面 → 同一張靜態圖 | 沒有 |

### 1.3 目前的點擊區與事件

- 點**故事卡墨丸**：P7-2 的彩蛋（D-48）。`MowanView.reactionNow()` 決定 REPLAY／LINE_ONLY／NONE；節日、Reduced Motion、沒有天氣時只換一句話（LINE_ONLY）。
- 日曆頁：`TearPageView.cornerAt` 在 ACTION_DOWN 時攔截**左下角與右下角 35%×35%** 的範圍，當作撕頁的起點。
- 天氣資訊（`sun` 那一行：天氣＋日出日落）在日曆頁的左下，**落在左下撕頁區裡**。

### 1.4 優先順序（`MowanDirector`）

GROWTH_STORY ＞ FESTIVAL_MAIN ＞ FESTIVAL_IDLE ＞ WEATHER_DAILY ＞ IDLE。天氣彩蛋只能排在 WEATHER_DAILY 這一層，有成長故事或節日時讓出（§5）。

### 1.5 Reduced Motion、小工具、換日

- Reduced Motion：`MowanTimeline.sample` 回傳 `stillClock(weather)` 那一格（晴 2000、雨 1050、雪 2000 ms），不動。
- 小工具：只有日曆頁的靜態圖，沒有大墨丸，**不做彩蛋**。
- 換日（D-44）：App 停在前景時跨過午夜不動日曆頁，回到 App（onResume）或撕完再重算。彩蛋播到一半換日，見 §5。

### 1.6 不能破壞的項目

W7（天氣日常）、P5、P6（節日）、P7-7（A1＋V2b 不位移版面）。本階段只新增測試目錄下的兩個檔案（`mowan/WeatherEgg.kt`、`WeatherEggPreviewTest.kt`），**沒有改 `app/src/main`**，所以 54 張 golden 與既有測試都不受影響。

## 2. 共同結構

```
0 ms      點擊天氣資訊：那一行底下亮一塊淡色（不改字、不改大小）
          ↓ 天氣素材進場（光點／雨滴／雪花）
小墨丸     察覺 → 反應（一個小動作，約 1.5–2.5 s）→ 把素材「送」往故事卡
          ↓ 接力：素材從日曆飄到故事卡（bridge，約 0.8–1.5 s）
大墨丸     素材落下 → 主演（約 3–4 s）
          ↓ 兩隻各自慢慢接回日常（blend 0.7–1 s，手臂用每一節的角度內插）
結束       小墨丸回到原本那張靜態圖；大墨丸回到天氣日常循環
```

- 素材只畫在日曆頁與故事卡上方的一層，**不改任何版面**：日曆高度、故事卡位置都不動。
- 接力的那一段素材飛越兩張卡片之間；正式整合時要一層蓋在兩者上面的透明 overlay（§4）。
- 素材是 1–6 個小圖形（光點、雨滴、水花、雪花、氣、水圈），沒有粒子系統。

## 4. 節奏、效能與整合風險

| # | 風險 | 嚴重 | 說明／建議 |
|---|---|---|---|
| R1 | **點擊區衝突** | 高 | 天氣資訊在 `TearPageView` 左下撕頁區裡，ACTION_DOWN 就被撕頁拿走。建議：在 `cornerAt` 排除天氣資訊那一行的範圍，或改成「點下沒有拖動（< touchSlop）且放開」才算點天氣，拖動仍是撕頁。要重新驗 P7-7 的撕頁測試。 |
| R2 | **和 D-48 衝突** | 高 | D-48 寫「日曆墨丸靜止、不能點；彩蛋從故事卡墨丸觸發」。方案 C 的入口改成天氣資訊、日曆墨丸會動，P7-9b 前要改這條決策。點故事卡墨丸的 P7-2 彩蛋要不要保留，也要一起決定。 |
| R3 | **小墨丸是 RemoteViews 靜態圖** | 高 | 日曆頁和桌面小工具共用 RemoteViews 版面。App 內要動畫，得在 App 內的日曆頁疊一個 `MowanView` 大小的 view 蓋住 `mowan_still`，播完再拿掉；小工具維持靜態、不做彩蛋。疊的 view 不能改版面高度（P7-7）。 |
| R4 | 接力素材要跨兩張卡 | 中 | 需要一層蓋在日曆與故事卡上面、不吃點擊的 overlay。日曆頁正在撕的時候不能播。 |
| R5 | 雪天小墨丸開頭跳一下 | 低 | 靜態圖是 `still = true` 的那一格；動畫的第一格雪花位置不同，會「啪」一下換掉。預覽已用同一格起跳，整合時要讓靜態圖與第 0 格完全一樣。 |
| R6 | 故事卡的字 | 中 | 彩蛋要不要換一句話（像 P7-2 的 LINE_ONLY）未定。換字時要固定高度，不能讓故事卡長高（P7-7）。 |
| R7 | 小尺寸看不清 | 中 | 60dp 的小墨丸：打噴嚏、縮一下的幅度很小（頭 14°、位移 < 1 單位），手機上可能只看得到光點。要在模擬器或實機看。 |
| R8 | 節奏 | 低 | 全長 7.6–9.4 s；小墨丸段約 3 s，大墨丸段約 4 s。雪天最長，若嫌長可把「湊近看」縮 0.4 s。 |
| R9 | 效能 | 低 | 每格兩次 `Mowan.render` ＋ 至多 6 個小圖形，6fps，只在點擊後跑 8 s 左右。比日常多一隻墨丸的成本，沒有粒子系統。**實機 Not tested。** |
| R10 | 更新頻率 | 低 | 墨丸 6fps 是既有風格；素材也照 6fps 走，雨絲仍是既有的 8fps。不另外加平滑補間。 |

## 5. 邊界情況的處理建議（只提案，沒有實作）

| 情況 | 建議 |
|---|---|
| 連點 | 播放中再點：忽略，不重播、不疊兩份；播完 1 s 內也忽略（避免連點變成一直重播）。 |
| 播到一半離開（切 App、鎖螢幕、開設定頁） | 立刻停，兩隻都直接回到日常（小墨丸回靜態圖），不續播、不補播。 |
| 播到一半天氣更新 | 播完目前這組，結束的 blend 接到**新天氣**的日常；若新天氣的姿勢差太多（例如晴→雨要出傘），改成在 blend 前直接切到新天氣日常，不做跨天氣內插。 |
| 播到一半換日 | 跟 D-44 一樣：不中斷，等播完、回到 App 或撕完再重算日曆頁。 |
| 正在撕頁 | 不能開始；撕頁開始時正在播的彩蛋立刻停。 |
| Reduced Motion | 不播動畫。天氣資訊亮一下、故事卡換一句天氣的話（固定高度），兩隻墨丸都停在 `stillClock` 那一格。 |
| 節日、成長故事 | 優先順序不變：成長故事播放時點天氣資訊不反應；節日日只換一句話（跟 P7-2 的 LINE_ONLY 一樣），不播天氣彩蛋。 |
| 沒有天氣資料／NONE | 不反應。 |
| 小工具 | 不做彩蛋。 |
| TalkBack | 天氣資訊要有「點兩下看墨丸的天氣小動作」的說明；播放本身不朗讀。**Not tested。** |

## 6. 我自己看過的項目

放大分鏡條（每 1/6 秒一格）逐格看過三組的大、小墨丸：

| 發現 | 處理 |
|---|---|
| 手臂在舉起／放下之間用點內插，中間那幾格手臂縮短、斷掉 | 改成每一節角度內插（`armLerp`），自動檢查手臂長度 0.85–1.2 倍 |
| 晴天小墨丸用伸展的長手臂揉鼻子，手穿過臉 | 改成打完噴嚏笑著指向故事卡 |
| 幾段手部動作太快（手尖一格移動 15–36 單位） | 放慢，手尖每格 ≤ 14 單位 |
| 雨天大墨丸仰頭時傘往右倒 32°，傘面蓋到故事卡文字 | 改成往外側（左）倒 16° |
| 雪天歡呼雙手舉直，被頭擋住，看起來少一隻手 | 改成往斜上方張開，手在頭的兩側 |

自動檢查（CI 的 `report.md`）：每一格比較關節位移、手臂長度、控制點數，三組都沒有問題（最大跳格見報告）。
