## 2. 天氣彩蛋：點故事卡上的墨丸

### 2.1 觸控區域（[`p7-home/7-story-entry.md`](p7-home/7-story-entry.md)、[`7-story-entry.png`](p7-home/7-story-entry.png)）

| 設定 | 墨丸可點範圍 | ≥ 48×48dp | 「卸下包袱」入口 | 重疊 | 最近距離 |
|---|---|---|---|---|---|
| 411dp 100% | 96×128dp | 是 | 66×48dp | 否 | 12dp |
| 411dp 200% | 96×128dp | 是 | 127×48dp | 否 | 134dp |
| 320dp 100% | 96×128dp | 是 | 67×48dp | 否 | 47dp |
| 320dp 200% | 96×128dp | 是 | 128×48dp | 否 | 336dp |

- 可點範圍就是 `MowanView` 本身（96×128dp）；包袱入口在右邊的文字欄底下，是另一個 View，兩者不重疊、也不在同一欄。
- 故事卡在 ScrollView 裡：用一般的點擊（`setOnClickListener`），手指移動就算捲動、不會誤觸發。
- 現在 `MowanView` 沒有任何點擊事件，不會跟既有行為衝突。日曆頁、TearPageView 都不改。
- 320dp、字體 200% 時故事卡不在第一個畫面裡（要往下捲）；**不自動捲動**。

### 2.2 觸發後的行為

| 情況 | 點故事卡上的墨丸 |
|---|---|
| 一般日子、有天氣 | 故事卡的那句話立刻換成天氣台詞（6 秒後回到故事，跟現在點天氣列一樣）；墨丸的天氣反應依 D-48 自然銜接（見 2.3） |
| 天氣反應還在銜接或播放中又點 | 不重啟動作；只把「6 秒後回到故事」從這次點擊重新計時 |
| 節日當天 | 只換台詞，不中斷主演出或待機 |
| Reduced Motion | 只換台詞；墨丸保持靜態代表姿勢 |
| 成長故事事件進行中 | **不打斷**：動作不變。台詞要不要換，見第 3 節第 2 題（建議：不換，事件結束後才接受點擊） |
| 沒有天氣資料 | 跟現在點天氣列一樣：重新抓天氣，台詞顯示「天氣讀取中…」，動作不變 |
| 翻到別天（日曆頁不是今天） | 照樣可以點：故事卡的墨丸演的是**今天**的天氣（故事卡不跟著翻頁） |
| 任何情況 | 不自動捲動頁面 |

拿掉天氣列以後，現在「點天氣列」的功能就移到故事卡的墨丸上（同一個 `playWeather()`）。

### 2.3 動畫怎麼觸發（D-48：等目前動作告一段落，或經由中性姿勢自然銜接）

現況：V3 的天氣日常是**一直循環**的動作（晴 5.5 秒、雨 4.2 秒、熱 3.2 秒、陰 6 秒、霧 5 秒、冷 2.8 秒、雪 4 秒一個週期），每個週期都會經過起始的站姿；點天氣時天氣沒變，所以現在動作不會重來（只換台詞）。

建議做法：

1. 點擊時，如果墨丸剛好在週期起點附近（離起點 ≤ 0.3 秒），直接從頭開始這個天氣的週期。
2. 其他時候，用約 0.3–0.4 秒從**目前的姿勢**平順過渡到**這個天氣週期的起始姿勢**（中性姿勢），再從頭播一次週期。不會突然跳回第一格。
3. 不新增美術：過渡是在既有的兩個姿勢之間插值，週期本身就是原本的天氣動作。
4. 雷雨：只重播撐傘的週期，**不因為點擊而強制打雷**（避免閃光）；打雷照原本的隨機排程。
5. 播放期間再點：照 2.2，不重啟。

替代做法（「等目前動作告一段落」）：等這個週期自然走完再從頭播。缺點是點了之後最多要等一整個週期（晴最多 5.5 秒）才看得出反應。**建議用 2 的中性姿勢銜接**，兩種都符合 D-48，請你選。

要新增的程式（實作時才做，這一停點沒有改）：`MowanTimeline` 加「重新開始目前的天氣週期、經過一段過渡」；`MowanView` 加點擊與判斷（節日、Reduced Motion、成長故事事件、播放中）。節日與故事事件的優先順序沿用 `MowanDirector.aboveWeather()`。

### 2.4 TalkBack

- 故事卡上的墨丸設成可聚焦的按鈕（焦點順序在故事卡的文字之前）。
- 朗讀：
  - 一般日子：「墨丸，今天晴，25 度。按鈕。按兩下，墨丸會對天氣做出反應」
  - 節日當天：「墨丸，今天是春節。按鈕。按兩下，聽墨丸說一句話」
  - 沒有天氣資料：「墨丸。按鈕。按兩下重新讀取天氣」
  - 成長故事事件進行中：「墨丸正在演故事」（建議這時不提供點擊動作）
- 觸發後：故事卡的台詞設成「禮貌」的動態區域（`accessibilityLiveRegion = polite`），TalkBack 會自動唸出新台詞；Reduced Motion 時也一樣。
- 按下的回饋：不加漣漪（避免在墨丸身上閃一塊灰色長方形）；反應本身與台詞就是回饋。是否加輕微震動，見第 3 節。
