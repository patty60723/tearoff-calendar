## 4. 天氣彩蛋：點日曆卡片裡的墨丸

標示圖：[`p7-home/5-egg-entry.png`](p7-home/5-egg-entry.png)（紅：撕頁起手區；藍：墨丸與建議的點擊範圍；綠：故事卡）。量測：[`p7-home/5-egg-entry.md`](p7-home/5-egg-entry.md)。

### 4.1 跟撕頁手勢的衝突（要先解決）

- 撕頁的起手區是日曆頁下方 35% 高 × 左右各 35% 寬（411dp 時每邊 124×124dp）。**日曆頁上的墨丸（60×80dp）整個落在右下的起手區裡**；現在在那裡一按下去就開始撕。
- 日曆頁本身沒有點擊事件（`isClickable = false`），沒有其他衝突。

**建議的判斷方式**：
1. 按下的位置在墨丸範圍內（墨丸外擴 6dp，至少 48×48dp）時，先不開始撕。
2. 手指移動超過系統的 touch slop（約 8dp）→ 照原本的方式從右下角開始撕（只晚幾個像素）。
3. 沒有移動、在長按時間（約 0.5 秒）內放開 → 算點墨丸，觸發彩蛋。
4. 墨丸範圍以外的起手區：完全照現在。

撕頁的手感只有「從墨丸身上起手」那一點點不同，而且撕頁還有「或按這裡撕下」按鈕。**這需要實機確認手感**（Robolectric、模擬器只能驗證判斷邏輯）。

### 4.2 互動流程

| 情況 | 點墨丸之後 |
|---|---|
| 一般日子、有天氣 | 故事卡的那句話立刻換成天氣的台詞（6 秒後回到故事，跟現在一樣）。故事卡上的墨丸重新播放今天的天氣反應：**等目前動作告一段落，或經由中性姿勢自然銜接，不突然跳回第一格**（D-48） |
| 天氣反應還在播時又點 | 不重新開始；只把「6 秒後回到故事」重新計時 |
| 節日當天 | 只換那句話，不中斷節日演出（主演出、待機都不打斷） |
| Reduced Motion | 只換那句話；墨丸停在代表姿勢，不動 |
| 成長故事事件進行中 | 不打斷（故事事件 > 主演出 > 待機 > 天氣） |
| 沒有天氣資料 | 跟現在點天氣列一樣：重新抓天氣，那句話顯示「天氣讀取中…」 |
| 日曆頁不是今天（翻到別天） | 不觸發（那一頁的墨丸沒有天氣） |

- 反應在故事卡上演（日曆頁上的墨丸是靜態圖，不會動）。411dp、一般字體時故事卡緊接在日曆下方，看得到；**320dp、字體 200% 時故事卡在畫面外**。要不要自動捲到故事卡，請你決定（建議：不自動捲動，只換文字；反應照樣播，捲下去就看得到）。
- 日曆頁上的墨丸本身不加動畫（D-16：小工具與日曆頁是一張靜態圖）。按下時的回饋建議只用系統的淡漣漪。

### 4.3 TalkBack 與 Reduced Motion

- 日曆頁上的墨丸設成可聚焦：「墨丸，今天晴，25 度。按鈕。按兩下，墨丸會對天氣做出反應」。TalkBack 的「按兩下」是點擊動作，不會觸發撕頁。
- 節日當天：「墨丸，今天是春節。按兩下聽墨丸說一句話」（只換文字）。
- Reduced Motion：觸發後朗讀那句台詞（`announceForAccessibility`），畫面上只換文字。
- 備案：如果點日曆頁墨丸的手感不好，也可以改成點**故事卡上的墨丸**（沒有手勢衝突、就是會動的那一個），或兩個都可以點。
