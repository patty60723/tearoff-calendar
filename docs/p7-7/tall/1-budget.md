# 最小 TALL 小工具（150×250dp）的垂直空間分配

單位 dp。文字欄是一個直式 LinearLayout（由上到下），日期數字 `weight=1` 拿剩下的空間；左下的天氣三行、右下的墨丸、山丘是疊在上面的（FrameLayout）。

天氣三行與墨丸是疊放的：不佔文字欄的高度，但文字欄最下面的 84dp 就是為了讓出它們的位置。
日期數字需要的最小可見高度：同一天在字體 100% 時的字形高度（一般日 27dp、春節 26dp）；字形約是字級的 0.7，所以日期元件至少要再高一些。
