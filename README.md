## 候選

| 代號 | 內容 | 狀態 |
|---|---|---|
| 0 | 現在的小工具：沒有節日外觀 | 既有（P5、P6-4b 為止） |
| A | 節日背景優先：頭飾＋手上道具＋一個節日背景（春聯／月亮／禮物），天氣環境讓位（雨傘照畫） | 現行程式的預設（P6-2 的 `SmallEnv.FESTIVAL`），D-16 的基礎 |
| B | A＋最多一個不衝突的簡化天氣線索 | **D-43 候選**（`SmallEnv.CUE`） |
| C | 只有頭飾與手上道具，節日背景、天氣環境都不畫（雨傘照畫） | **48dp 極簡候選**（`SmallEnv.MINIMAL`） |

既有規則（不在這次審核範圍，候選都照用）：小工具 V3 一律是簡化版（角色 < 72dp，D-25）；節日當天不播天氣日常動作（D-31）；雨、雷雨、雪看不到月亮（D-37）；小尺寸每個節日只留一個背景元素（春聯、月亮、禮物；襪子不畫）；48px 禮物只留紅緞帶（D-30）。

B 的規則（D-43）：春聯在左上、月亮在右上、禮物在右下。
- 晴、熱：太陽（有月亮時不畫，本來就這樣）
- 陰：一朵雲；中秋（月亮）時不畫
- 雷雨：一朵烏雲（左上）；春節（春聯也在左上）時不畫
- 雨、雪：只留右邊兩條雨絲／兩片雪花
- 霧：腳邊那一條
- 冷：沒有環境
