# 手撕日曆

Android 桌面小工具：傳統手撕日曆的樣子，每天一頁，有農曆、節氣、節日和農民曆的宜忌。

## 安裝

1. 用手機打開這個 repo 的 **Releases → 最新版**，下載 `tearoff-calendar.apk`。
2. 點下載好的檔案安裝。第一次會要求允許「安裝不明來源的應用程式」，允許瀏覽器安裝即可。
3. 打開「手撕日曆」App，按「把小工具放到桌面」；或長按桌面 →「小工具」→ 找到「手撕日曆」。

之後有新版本，一樣下載安裝就會蓋過舊版，不用先解除安裝。

## 目前有什麼（第一版）

- 4×2 的標準版面，拉窄到 2 格寬會換成精簡版面
- 西曆日期、星期、農曆、干支年與生肖
- 宜忌各 4 項（精簡版 3 項），點小工具打開 App 看完整的宜忌與沖煞
- 週末和台灣國定假日印紅字；節日或節氣印在日期下面
- 每天午夜後自動換頁

## 規劃中

1. 火柴人動畫：平日依宜忌做動作，節日換造型
2. 自訂排版：選版型、各區塊顯示/隱藏與排序、字體大小、配色
3. App 內撕頁動畫
4. 每日簽到與扭蛋：火柴人的配件與故事
5. 台灣的補假與調整放假（每年人事行政總處公布後更新）

## 開發

- Kotlin，最低支援 Android 8.0（API 26）
- 農曆與宜忌：[lunar-java](https://github.com/6tail/lunar-java)（MIT），離線計算；簡體詞彙在 `Hant.kt` 轉成繁體
- 推到 GitHub 後由 Actions 跑測試並打包；`main` 分支會更新 Releases 的「最新版」
- `app/debug.keystore` 是刻意放進 repo 的測試用簽章，讓每次打包的 APK 能直接覆蓋安裝。之後若要上架 Google Play，要另外產生正式簽章，且不能放進 repo。
